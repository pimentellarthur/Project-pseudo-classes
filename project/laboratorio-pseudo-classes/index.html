Laboratório de Pseudo-classes

:hover

“quando o mouse passa por cima”

O botão muda enquanto o cursor está sobre ele.

button:hover

:active

"O usuário está pressionando/clicando o elemento neste momento?"

O botão muda enquanto o cursor pressiona ele.

button:active

:focus

"O elemento em foco no momento"

O botão muda quando o clica.

button:focus
